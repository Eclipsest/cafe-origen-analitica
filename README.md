# cafe-origen-analitica

## ¿Qué es este proyecto?

Es un programa sencillo para revisar las ventas de Café Origen. Los datos están en `src/datos.js` y las funciones para analizarlos están en `src/analitica.js`.

## ¿Cómo lo ejecuto?

Necesitas tener Node.js instalado. Abre una terminal en la carpeta del proyecto y ejecuta:

```bash
node src/reporte.js
```

Para comparar las funciones hechas con ciclos y con métodos de arreglo, ejecuta:

```bash
node src/verificar.js
```

## ¿Qué preguntas responde?

* ¿Cuánto se vendió en total y cuántas unidades se vendieron?
* ¿Cuál fue el valor promedio y cuál venta tuvo el mayor valor?
* ¿Cuánto se vendió en cada ciudad?
* ¿Cuántas unidades se vendieron de cada producto?
* ¿Qué tres productos generaron más dinero?
* ¿Qué ventas y qué total hubo en un día elegido, incluso si ese día no tuvo ventas?
